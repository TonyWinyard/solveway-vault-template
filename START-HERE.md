# Start here

This is your vault. It is a plain folder of notes on your own laptop, backed up to your own private GitHub repository.

## Three rules

1. **Nothing secret.** No passwords, no client names, no personal details about anyone. Your AI reads everything in here and sends what it reads to its own company to get you an answer.
2. **Private stays on your laptop.** Anything in the `Private` folder is never sent to GitHub.
3. **Never change the course files. Copy them first.** They are updated before each session, and your changes would be overwritten.

## What each folder is for

| Folder | What goes in it |
|---|---|
| `Programme` | Session notes and course files |
| `Inbox` | Quick notes, before you know where they belong |
| `Tasks` | Your to-do list |
| `Meetings` | One note per meeting |
| `Processes` | How a job gets done, step by step |
| `Automations` | Everything you build |
| `Prompts` | Prompts that worked, so you can use them again |
| `Private` | Anything that stays on this laptop only |

## The habit

- **Before each session:** in GitHub Desktop, click Fetch, then Pull the course files.
- **During:** take your notes in Obsidian.
- **After:** commit and push.

The last one is the only one people drop, and it is the one that saves the work.
